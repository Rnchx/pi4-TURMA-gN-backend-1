# Changelog

## [1.1.0] - 2026-11-15

- Substitui a integração HTTP interna pelo protocolo TCP/JSON entre Node.js e Java em contêiner Docker.
- Adiciona cadastro e login com validação Java, Argon2id, sessões opacas e limitação de tentativas.
- Aceita e-mails de qualquer domínio válido e senhas com no mínimo oito caracteres.
- Persiste data de nascimento, calcula idade no Java e protege produtos demonstrativos para maiores de 18 anos.
- Adiciona perfil, foto persistente, edição de nome, troca de senha e exclusão permanente da conta.
- Substitui dinheiro por boleto nos quatro métodos de pagamento demonstrativos.
- Inclui migrations incrementais, volume de fotos, testes Docker integrados e documentação dos contratos.
